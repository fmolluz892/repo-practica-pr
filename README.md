# Recomendaciones de la clase

ESTA ES MI APORTACION

Pequeño proyecto de práctica para aprender a trabajar con **fork** y **Pull Request** en GitHub.

## Qué es esto

Una lista colaborativa de recomendaciones (un libro, una herramienta, una serie, lo que quieras) de la clase de Desarrollo Full Stack, Control de Versiones y Pruebas de Software.

## Cómo participar

1. Haz un **fork** de este repositorio (botón arriba a la derecha).
2. Clona tu fork.
3. Crea una rama con tu nombre: `git switch -c anade-tu-nombre`.
4. Añade **una línea** a `RECOMENDACIONES.md`, al final de la lista, siguiendo el formato que ya hay.
5. Haz commit, `git push` a tu fork, y abre una Pull Request contra este repositorio.

No edites las líneas de tus compañeros, solo añade la tuya al final. Así cada Pull Request es sencilla de revisar.
